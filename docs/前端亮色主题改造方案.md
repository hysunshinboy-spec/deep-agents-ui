# 前端亮色主题改造方案（实现交接文档）

> 版本：2026-09-18 v1 ｜ 适用仓库：`deep-agents-ui`（Next.js 16 + React 19 + Tailwind + Radix）
> 本文档自包含：实现 AI 不需要访问其他资料即可完成主题改造。
> 三套高保真参考实现（单文件 HTML，浏览器直接打开）：`../sketches/004-light-warm/`、`../sketches/005-light-fresh/`、`../sketches/006-light-cream/`（各含 `index.html` + `README.md`）

## 0. 背景与决策

- **现状**：主题机制为 `data-theme` 属性 + CSS 变量（`src/app/globals.css`，699 行），主题清单在 `src/lib/theme.ts`（teal/blue/mint/violet/sand 五套，默认 teal）。机制保留，皮肤全部重做。
- **决策**：弃用原深色/ pastel 方向，改**明亮轻快**配色。三套候选已完成高保真 mockup，**推荐 ④ 暖纸为默认主题**；⑤⑥ 作为可选切换项一并实现（成本只是两个 CSS 块）。
- **布局**：mockup 采用"平衡工作台"三栏骨架（线程 / 对话 / 产物面板）。**本期主题改造不改布局**，只换肤；布局升级另行立项。

## 1. 主题 token（三套完整定义）

全部写入 `globals.css` 的 `:root[data-theme="..."]` 块。命名沿用现有变量的语义；若现有变量名不同，以现有为准映射，不要新增并行体系。

### ④ warm 暖纸书房（推荐默认）

```css
:root[data-theme="warm"] {
  --bg:#f5f4ed;  --panel:#efece1;  --elev:#faf9f5;  --elev2:#f0eee4;
  --line:#e4e1d2;  --line-sub:#eceadf;
  --t1:#141413;  --t2:#4d4c48;  --t3:#71706a;  --t4:#8f8d80;
  --accent:#c96442;  --accent-hover:#b55637;  --accent-soft:rgba(201,100,66,.12);
  --ok:#2f855a;  --ok-soft:rgba(47,133,90,.1);
  --shadow:0 10px 30px rgba(80,66,40,.08);
}
```

### ⑤ fresh 晨间清爽

```css
:root[data-theme="fresh"] {
  --bg:#ffffff;  --panel:#f7f8fa;  --elev:#ffffff;  --elev2:#eef1f4;
  --line:#e5e8ec;  --line-sub:#eef1f4;
  --t1:#111827;  --t2:#3f4756;  --t3:#6b7280;  --t4:#9aa1ac;
  --accent:#0d9488;  --accent-hover:#0f766e;  --accent-soft:rgba(13,148,136,.1);
  --ok:#059669;  --ok-soft:rgba(5,150,105,.09);
  --shadow:0 10px 30px rgba(15,23,42,.07);
}
```

### ⑥ cream 奶油轻快

```css
:root[data-theme="cream"] {
  --bg:#fffdf8;  --panel:#faf5ec;  --elev:#ffffff;  --elev2:#f7f1e4;
  --line:#efe7d6;  --line-sub:#f4eee0;
  --t1:#292524;  --t2:#5b554d;  --t3:#7d7466;  --t4:#a8a29e;   /* t3 已从 #857d72 加深,见 §6 对比度 */
  --accent:#ea580c;  --accent-hover:#c2410c;  --accent-soft:rgba(234,88,12,.12);
  --ok:#16a34a;  --ok-soft:rgba(22,163,74,.1);
  --mint:#e7f6ec; --peach:#fdeee0; --sky:#e8f2fb;             /* pastel 点缀,仅图标/标签用 */
  --shadow:0 12px 32px rgba(120,90,40,.1);
}
```

**对比度实测（WCAG，bg 为背景）**：

| 主题 | t2 正文 | t3 次级 | 白字按钮 |
|---|---|---|---|
| ④ warm | 7.80 AAA | 4.50 AA | 3.90（hover 4.83） |
| ⑤ fresh | 9.35 AAA | 4.83 AA | 3.74（hover 5.47） |
| ⑥ cream | 7.24 AAA | 4.53 AA（修正后） | 3.56 |

按钮白字对比度 3.5–3.9 为业界常见妥协（12–13px 500 字重），如要求严格 AA，按钮背景统一用 `--accent-hover` 色。`--t4` 全部主题低于 4.5，**只允许用于 mono 元数据/水印级文字（≥10px 装饰性）**，不得用于正文。

## 2. 排版系统（三套共用）

```css
--font-sans: Inter, -apple-system, "PingFang SC", sans-serif;
--font-serif: "Noto Serif SC", Georgia, "Songti SC", serif;   /* 仅标题/引用 */
--font-mono: "JetBrains Mono", ui-monospace, SFMono-Regular, Menlo, monospace;
```

- 字体加载：`<link>` Google Fonts（`Inter:wght@400;500;600` + `Noto+Serif+SC:wght@500;600;700` + `JetBrains+Mono:wght@400;500`），在 `layout.tsx` 的 `<head>`；生产建议自托管。
- 全局 `font-feature-settings:"cv01","ss03"`（Inter 几何替代字形，Linear 同款处理）。
- 字阶：

| 用途 | 字号/行距 | 字重 | 字体 |
|---|---|---|---|
| AI 报告正文 | 14.5px / 1.8 | 400 | sans |
| 报告节标题 h2 | 19px | 600 | **serif** |
| 报告大标题 h1 | 24–30px | 600–700 | **serif** |
| 用户消息 | 14px | 400 | sans |
| 工具卡/元数据 | 12.5 / 11.5px | 400–500 | sans / mono |
| 侧栏线程 | 13px | 400 | sans |
| 品牌字 | 17px | 600 | **serif**（accent 色斜体 emphasis） |

## 3. 组件规格（基准 004；标注 ⑤⑥ 差异）

以下组件样式在 mockup 中均已实现，实现时**以 mockup CSS 为准逐组件移植**。关键件：

1. **侧栏线程**：`padding 8/10, radius 7–10px`，选中态 = `--elev` 底 + `--line` 边 + 左侧 accent 圆点；hover = `rgba(0,0,0,.025)`。**⑥ 半径 10px 且选中带投影**。
2. **工具调用卡**：`--elev` 半透明白底（⑤用纯白+灰底展开区），`radius 10–12px`，头部行 = mono tag（accent-soft 底）+ 名称 + ✓ + 右侧 mono 元数据 + chevron；展开区 `background: rgba(0,0,0,.015)`（⑤用 `--panel`），mono 11.5px。
3. **sub-agent 行**：转圈 spinner = `12px border 1.5px accent`，行内显示 `名称 · 步骤进度 · 耗时`。
4. **报告区**：正文 `--t2` 1.8 行距，`<strong>` 用 `--t1`；`blockquote` = 左 2px accent 边 + serif 15px + `--t3`（⑥ 加 pastel 渐变底）；`code` = `rgba(0,0,0,.05)` 底（⑤用 `--elev2`），mono 0.88em。
5. **引用文件行（cite）**：白底圆角行，右侧 mono 字数；hover 边框变 accent。
6. **产物面板**：文件行左侧 26–28px 图标块；**⑥ 图标用 pastel 底色（--sky/--mint）**；选中 = 左 2px accent inset 边。
7. **任务清单**：`13–14px` 方框 checkbox，完成 = `--ok-soft` 底 + 删除线。
8. **输入框**：白底圆角卡（`radius 14–18px`，⑥ 最大）+ `--shadow` 投影 + focus 边框 `accent 45–50%` 透明；chip = pill 边框按钮；发送键 = accent 底白字（⑥ 用 135° 渐变 + 投影）。
9. **状态灯**：运行中 = `--ok` 底 pill，`● agent 运行中`。

## 5. 实现步骤建议

1. `grep -rn "rgba(255,255,255" src/ | grep -v globals.css` → 列出暗色假设硬编码，逐处改变量（这是最容易漏的活）
2. `theme.ts` + `i18n.ts` 换清单（先改这里，界面立刻可切换但颜色未跟上）
3. `globals.css` 写三个新主题块，保留旧块不删（回滚方便），验证后清理
4. 逐组件对照 mockup 修样式（§3 清单），重点：工具卡、报告区、输入框
5. sonner toaster、对话框等全局件过一遍
6. 保留 `violet` 深色主题作为切换项验证"亮→暗"无中间态闪烁
